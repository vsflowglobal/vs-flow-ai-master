- Quant / Backtest Lab
- VFTC Trade Card
- Trading Journal

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Streamlit Cloud
Set the repository root as the app source and use `app.py` as the main file.

For AI Chart Analyzer, add this secret in Streamlit:
```toml
OPENAI_API_KEY = "sk-..."
```

Never commit API keys to GitHub.
